# RAG Architecture

## 1. Overview

RAG stands for Retrieval-Augmented Generation.

RAG combines information retrieval with a Large Language Model (LLM).

The main pipeline is:

Documents
    ↓
Chunking
    ↓
Embeddings
    ↓
Vector Store
    ↓
Retrieval
    ↓
Relevant Context
    ↓
LLM
    ↓
Grounded Answer + [source_id]

## 2. Indexing Pipeline

Documents
    ↓
Split documents into smaller chunks
    ↓
Generate embeddings for each chunk
    ↓
Store embeddings with the original text and metadata
    ↓
Store them in a vector database

## 3. Query Pipeline

User Question
    ↓
Generate embedding for the question
    ↓
Search the vector store
    ↓
Retrieve the most relevant chunks
    ↓
Build context from retrieved chunks
    ↓
Send question + context to the LLM
    ↓
Generate a grounded answer
    ↓
Cite the source using [source_id]

## 4. Main Components

### Documents
Original knowledge such as company documentation, PDFs, FAQs, policies, and manuals.

### Chunking
Breaking large documents into smaller pieces so relevant information can be retrieved efficiently.

### Embeddings
Converting text into numerical vectors that represent semantic meaning.

### Vector Store
A database or storage system used to store embeddings and associated information.

### Retrieval
Finding the most relevant chunks for a user's question.

### Context
The retrieved information supplied to the LLM.

### LLM
Generates the final answer using the supplied context.

### source_id
An identifier attached to retrieved information so the answer can cite where the information came from.

## 5. Core Principle

The LLM should answer using the retrieved context rather than relying on unsupported information.

The goal is:

Retrieve relevant information → Give it to the LLM → Generate a grounded answer.

## 6. Important Terms

- Chunk: A smaller section of a document.
- Embedding: Numerical representation of text meaning.
- Vector: Numerical representation used for similarity comparison.
- Semantic Search: Searching based on meaning rather than exact words.
- Top-K: Number of most relevant chunks returned by retrieval.
- Metadata: Additional information associated with a chunk.
- Grounding: Restricting the answer to trusted supplied information.
- Hallucination: An unsupported or incorrect answer generated by an LLM.
