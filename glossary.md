\# Day 1 - LLM Glossary



\## 1. LLM

LLM stands for Large Language Model. It is an AI model that understands and generates text by predicting tokens based on patterns learned during training.



\## 2. Token

A token is a small piece of text processed by an LLM. Tokens are used to measure the input and output sent to and generated by the model.



\## 3. Context Window

The context window is the amount of information an LLM can consider in one request, including instructions, conversation history, input, and output.



\## 4. Temperature

Temperature controls how random or varied the model's response can be. A lower value usually gives more predictable responses, while a higher value allows more variation.



\## 5. System Message

A system message gives the model instructions about its behavior, role, or rules.



\## 6. User Message

A user message contains the actual request or question given to the LLM.



\## 7. Assistant Message

An assistant message is the response generated by the LLM. Previous assistant responses can also be included as conversation history.



\## 8. Stateless

A stateless API request does not automatically remember previous requests. If an application needs conversation memory, it must send the required history again.



\## 9. Hallucination

A hallucination happens when an LLM gives information that sounds correct but is actually false or unsupported.



\## 10. API Key

An API key is a secret credential used by an application to authenticate when accessing an API. It must be kept private.
